# ActivePaws — Frontend

Interfaz de la tienda ActivePaws (React + Vite + Tailwind CSS), conectada a la API real en `../backend` (Express + MongoDB).

Ver el `README.md` en la raíz del proyecto para las instrucciones completas de instalación y las credenciales de prueba.

```bash
npm install
cp .env.example .env   # VITE_API_URL=http://localhost:4000/api
npm run dev
```
